AI coding assistants generate functional UI. But functional isn't the bar anymore.

I spent two weekends building something I couldn't find anywhere: a design skill for AI coding tools.

UX Audit is an open-source skill file that teaches Claude Code, Cursor, and Codex how to think about UI/UX — so the interfaces they generate have hierarchy, feedback, accessibility, and intent.

What's in it:
→ 12 core design principles (each with do/don't code examples)
→ 13 deep-dive reference docs (accessibility, responsive, typography, forms, overlays...)
→ 7 component checklists (tables, modals, dashboards, forms...)
→ Two modes: Guide (build it right) and Review (audit what exists)

It's not a library. It's not a framework. It's a single file that rewires how your AI thinks about design.

The before/after is stark. A delete confirmation goes from "Are you sure? Yes/No" to naming what's being deleted, stating consequences, providing accessible focus management, and using action-specific button labels.

Install in 30 seconds. Apache 2.0 licensed.

→ github.com/narenkatakam/ux-audit

If you're shipping UI with AI assistance, this is the missing piece between "it works" and "it's well-designed."
